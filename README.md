# AI Kakak Landing

Demo landing page for **AI Kakak** — WhatsApp AI Assistant for Malaysian SMEs.

Built as a live demonstration of Grok's multi-tool workflow using:
- Linear (project + issues)
- Notion (specs)
- Excalidraw + Figma (diagrams)
- Canva (assets folder)
- Google Drive (project folder)
- Google Calendar (sprint event)
- GitHub (this repo)
- Vercel (deployment)
- Gmail (notification)

## Live

Deployed via Vercel connected tool.

## Local

Just open `index.html` or serve with any static server.
